# Fiche Google Play : Mana Orbit

Tout ce qu'il faut copier dans la Play Console, en français (langue par défaut) puis en anglais (traduction ajoutée dans **Présence sur le Play Store › Fiche principale › Gérer les traductions**).
Les textes à coller sont dans les blocs gris : copie le bloc entier. Les longueurs sont vérifiées (limites de Google entre parenthèses).

Visuels : dans ce dossier, générés par `node tools/store-assets.mjs` (voir la fin de ce fichier).

Ordre conseillé des captures : accueil, collection, valeur dans le temps, decks à monter, viewer de deck, prix d'une liste, scan, échange. Les deux premières comptent le plus : ce sont celles que montrent les résultats de recherche.

Les captures sont celles de la vraie appli (thème sombre), avec une collection d'exemple : 515 cartes (1 030 exemplaires), environ 2 340 €, quatre decks. Les images des cartes y sont des cartes factices dessinées par le script (aucune illustration réelle) ; les vrais téléphones affichent les images Scryfall. La bannière ne contient ni logo ni symbole de Wizards of the Coast. Aucune capture ne montre le bandeau publicitaire.

### Refaire les visuels

```
node tools/store-assets.mjs            # tout : bannières + 16 captures (≈ 2 min)
node tools/store-assets.mjs feature    # bannières seulement
node tools/store-assets.mjs shots en   # captures anglaises seulement
RAW=1 node tools/store-assets.mjs shots   # garde aussi les écrans bruts (shots/store/, non versionné)
```

Prérequis : `tests/node_modules` installé (Playwright), Chromium dans `/opt/pw-browsers/chromium` (ou la variable `CHROMIUM`), port 18980 libre. Aucune connexion Internet : le script sert l'appli avec le monde des tests et simule Scryfall. Les polices de l'appli (Bricolage Grotesque, Instrument Sans, licence OFL) sont dans `tools/fonts/` ; sans elles, le script prend les polices du système.
Les légendes, les données d'exemple (collection, decks, historique) et l'ordre des écrans sont en tête de `tools/store-assets.mjs` (`SHOTS`, `DB_TXT`, `DECKS`).
